# Approved docks assets

Generated by `npm run prepare:approved-art` (`scripts/prepare-approved-art.mjs`). It writes `approved-models.glb`, `src/generated/approved-models.js`, `src/generated/approved-textures.js` and `manifest.json`.

## Colour maps are embedded as WebP

The game embeds the two colour maps as `data:image/webp` to keep the bundle small:

| Texture | Embedded WebP | PNG source of record |
|---|---|---|
| `approved_teal_color` | `assets/art-proof/teal-plank-atlas-v1.webp` | `assets/art-proof/teal-plank-atlas-v1.png` |
| `approved_rock_color` | `assets/art-proof/nature/Rocks_Diffuse.webp` | `assets/art-proof/nature/Rocks_Diffuse.png` |

Both sources are opaque RGB, so the WebP files carry no alpha. `webp-encode.json` records the encoder, chosen quality, PSNR against the decoded PNG, and the SHA-256 of each source and output. `manifest.json` repeats those fields. The prepare script refuses to run if a WebP no longer matches `webp-encode.json`.

## Redo the encoding

Node has no WebP encoder, so `scripts/encode-approved-webp.mjs` encodes in headless Chrome (`CHROME_PATH` overrides the Chrome location):

```
node scripts/encode-approved-webp.mjs
npm run prepare:approved-art
```

For each PNG the encoder tries qualities 0.92 to 0.99 plus lossless (quality 1) and keeps the smallest whose RGB PSNR is at least 42 dB (`MIN_PSNR` in the script). It rewrites the WebP files and `webp-encode.json`. The Chrome version is part of the record, so a different Chrome may produce different bytes.

The teal atlas only reaches 42 dB when lossless; lossy WebP tops out near 40.6 dB (4:2:0 chroma subsampling). Lower `MIN_PSNR` to trade fidelity for size.
